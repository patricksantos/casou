# Patrick & Sabrina - Landing Page de Casamento

Uma landing page minimalista e responsiva para celebrar o casamento de Patrick e Sabrina.

## 🎉 Características

- **Fotos do Pré-Wedding**: Galeria com visualização das fotos do pré-casamento
- **Contagem Regressiva**: Contador automático até o dia 1º de agosto de 2026
- **Lista de Presentes**: 12 opções criativas e sofisticadas de presentes
- **Design Minimalista**: Interface limpa com paleta de cores elegante (cores terra e dourado)
- **Responsivo**: Totalmente adaptado para dispositivos móveis e desktop
- **Navegação Suave**: Menu flutuante com scroll suave entre seções

## 🛠️ Tecnologias

- **React** 18.2.0
- **TypeScript** 5.3.0
- **Vite** 5.0.0
- **CSS3** (com responsividade)

## 📦 Instalação

```bash
npm install
```

## 🚀 Desenvolvimento

Para iniciar o servidor de desenvolvimento:

```bash
npm run dev
```

O site estará disponível em `http://localhost:5173`

## 🏗️ Build

Para criar a versão de produção:

```bash
npm run build
```

Os arquivos compilados estarão na pasta `dist/`

## 📋 Estrutura do Projeto
